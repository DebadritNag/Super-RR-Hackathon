## Reconciliation of the earlier '48 shortened innings' wording

The data contain 50 shortened regulation innings. `pressure_rules_v1.json` mentions 48 in a sensitivity note. The count by limit source is {'CARRIED_FROM_FIRST_INNINGS_UNVERIFIED': 2, 'REVISED_FIELD': 48}: 48 innings have the limit in the revised-overs field and the remainder carry the first-innings limit to the second innings without verification. The note's 48 therefore undercounts by the carried innings; the sensitivity 'exclude shortened innings' must use all 50, which is what `dls_exclude_primary` already does. The config file is left unchanged (no code reads the note).
